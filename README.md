Inventory & Supply Chain Optimization
Project Overview
This project analyzes inventory levels, stockout events, reorder patterns, and supplier delivery performance to help a retail business improve product availability and reduce excess stock.
Tools Used
- MySQL — data storage and SQL analysis
- Power BI — dashboard development
- Excel / Power Query — data cleaning and preparation
Project Contents
- SQL/ — SQL queries for inventory and supplier analysis
- Documentation/ — project background, methodology, and findings
- PowerBI/ — dashboard-related documentation
Key Objectives
1. Identify products with frequent stockouts.
2. Evaluate supplier delivery performance.
3. Analyze inventory levels across stores.
4. Recommend better restocking strategies.
Project Status: In progress.
